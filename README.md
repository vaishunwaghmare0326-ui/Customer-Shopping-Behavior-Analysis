# 📊 Customer Shopping Behavior Analysis

## Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, PostgreSQL, and Power BI. The goal is to analyze customer shopping behavior, identify meaningful insights, and present the findings through an interactive dashboard and a professional report.

The project covers the complete analytics process—from loading and cleaning the dataset to exploratory data analysis (EDA), SQL querying, dashboard creation, and presentation.

---

## Dataset

The dataset contains customer shopping information, including demographic details, purchase behavior, product categories, payment methods, and transaction data.

### Features Analyzed

* Customer demographics
* Purchase Amount
* Product Categories
* Payment Methods
* Shopping Frequency
* Customer Reviews
* Subscription Status
* Seasonal Purchases

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python.
* Verified data types and structure.
* Explored the dataset dimensions and columns.

### 2. Data Cleaning

* Checked for missing values.
* Removed duplicate records.
* Corrected inconsistent data.
* Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)

* Generated summary statistics.
* Analyzed customer purchasing behavior.
* Explored category-wise sales.
* Identified trends and patterns using visualizations.

### 4. SQL Analysis (PostgreSQL)

Performed SQL queries to answer business questions, including:

* Total revenue analysis
* Top-selling product categories
* Customer segmentation
* Average purchase amount
* Ranking customers using window functions
* Department and category-wise analysis

### 5. Power BI Dashboard

Built an interactive dashboard featuring:

* Sales Overview
* Revenue KPIs
* Category Analysis
* Customer Insights
* Purchase Trends
* Interactive Filters and Slicers

### 6. Reporting & Presentation

* Created a detailed project report summarizing the analysis and findings.
* Designed a professional presentation using Gamma to communicate the project workflow and key insights.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook from start to finish.
5. Import the cleaned dataset into PostgreSQL and execute the SQL queries.
6. Open the Power BI (.pbix) file to explore the interactive dashboard.
7. Review the project report and presentation for a complete summary of the analysis.
